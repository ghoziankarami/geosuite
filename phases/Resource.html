Estimation Setup

Select target element, domains to estimate, and declustering parameters. Default = auto-pilot (conservative parameters).

Variography Analysis

Experimental variogram + model fit per direction. Nugget ratio < 80% is considered healthy (Sinclair & Blackwell 2002).

Block Model Setup

Extent from data + block size XYZ. Rule of thumb: block size ≈ ¼–½ × nearest data spacing.

Block Grade Estimation

Three parallel methods: IDW (inverse distance weighted, p=2), Ordinary Kriging (variogram-based BLUE), NN (nearest neighbor for validation). Search ellipsoid default = 1.5× variogram range, widened for sparse drilling up to a 3× cap — see the radius/range ratio on the Estimation tab.

Cross-Validation

Leave-one-out validation. Target: R² > 0.4 for OK, slope ≈ 1.0, mean residual ≈ 0 (no global bias).

Swath Plot

Spatial bias validation. Drillhole grade vs estimate per X/Y/Z slice. Similar trends = unbiased; divergent = re-tune variogram/search.

Preliminary Confidence Class

Preliminary computational screening based on kriging variance, neighbor count, and distance to nearest composite. Cross-validation slope is shown as a global validation diagnostic. This is not a final JORC/KCMI classification; geological continuity, SOR, domains, modifying factors, and Competent Person review remain required.

Grade-Tonnage Decision Curve

Tonnage & mean grade sensitivity vs cutoff. Primary output for economic study (Stage 04 Mining Studies).

3D Block Model Viewer

Visualize blocks with color-coded grade + composite drillholes as lines. Filter by preliminary confidence screen or cutoff.

Resource Handoff Report

Handoff summary + variogram/validation evidence + preliminary confidence rationale. This is a KCMI-style working report, not a certified Mineral Resource statement.

Sample Dataset — Thalanga VMS

Thalanga Volcanogenic Massive Sulphide (VMS) deposit — Charters Towers region, Queensland, Australia. Pb-Zn-Cu-Ag VMS host rock dataset, used as industry-standard training data for drillhole workflows.

Embedded sample data: Thalanga RGMWP — 40 holes · 1,241 composites (output of Stage 01).

Data source: Queensland Government Geoscience Data — ds100103 (public domain, Creative Commons Attribution).

Attribution: Geological Survey of Queensland, Department of Resources, Queensland Government.

Variogram Models

4 model fits available: Spherical (most common, finite range), Exponential (asymptotic, longer range), Gaussian (smooth, parabolic origin — use with high nugget), Power (fractal, no sill).

Anisotropy: rMaj (major direction range), rSemi (semi-major), rMin (minor). Auto-fit uses least-squares on experimental variogram (azimuth + dip search).

Estimation Methods

IDW (Inverse Distance Weighted) — fast, deterministic, no spatial covariance assumption.
Ordinary Kriging — BLUE estimator, requires variogram model. Outputs kriging variance for classification.
Nearest Neighbor — sanity check baseline.

Limitations: No sub-discretization (4×4×4) — block centroid only → hand off to GeostatsPy. Octant search is available but off by default (Estimation tab → Octant search) — turn it on when samples cluster on one side of a block.

Classification — KCMI/JORC

High confidence — dense data (small drillhole spacing), low kriging variance.
Medium confidence — moderate density, moderate variance.
Low confidence — extrapolated, high variance.

These tiers are a computational screen, not Mineral Resource categories. KCMI 2017 and JORC 2012 set no numeric thresholds: Measured / Indicated / Inferred are assigned by a Competent Person from geological and grade continuity, data quality and modifying factors. Adjust the screen's thresholds in the Classification tab.

Reference: KCMI 2017 (Komite Cadangan Mineral Indonesia), JORC Code 2012 (Australasian Code for Reporting of Exploration Results, Mineral Resources and Ore Reserves).
