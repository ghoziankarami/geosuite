Import — 4 CSV Files (auto-classify)

Drop all 4 CSV files at once (Collar + Survey + Assay + Geology). The system auto-classifies by filename first (looks for collar/survey/assay/geology|litho), falling back to header signature.

If you skip the upload, the system uses the embedded Thalanga VMS sample. If you upload only some files, the rest stay as sample data.

Import Options

Override how numbers are read, and declare your coordinate system. Both are auto-detected — change them only if the import looks wrong.

Assign midpoint coordinates in Column Mapping when needed. This mode preserves supplied positions; it does not reconstruct or verify a directional survey. Empty coordinates remain missing.

The coordinate system is recorded in your project metadata and written into exports (satisfying the KCMI 2017 / JORC 2012 requirement that the CRS be stated). It also enables the satellite basemap on the spatial map.
