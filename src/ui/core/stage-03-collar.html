Collar — Drillhole Header Data

One row per drillhole: hole_id, collar coordinates (X, Y, Z) and total depth. Click a cell to edit, or use Add Row.

Standards for collar records

Collar positions must be surveyed (GPS or local grid) per KCMI 2017 Ch1 1.1 and JORC 2012 1.15. The coordinate system must be stated. Collar elevation (Z/RL) should be surveyed, not estimated from topography.
